    ```json

      "session_id": "s_ca99bb83",
      "phase": "pick",
      "offer_id": "monday-cartoons.myshopify.com:gid://shopify/ProductVariant/68033173323939:50",
      "pick_id": "gid://shopify/Product/15536111124643",

    ```

  - Multipart WAV (`session_id`, `audio`) or JSON (`{"session_id": "...", "text": "..."}`).
  - Response includes `session_id` and `reply.offer_id` (plus `reply.pick_id`, `reply.variant_id`, `reply.price_minor`, `reply.speech`, `reply.audio_b64`):
    ```json
    {
      "session_id": "s_ca99bb83",
      "reply": {
        "speech": "...",
        "pick_id": "gid://shopify/Product/15536111124643",
        "variant_id": "gid://shopify/ProductVariant/68033173323939",

        "did_research": true
      }
    }
    ```
- **Offer-Bound Tap (`POST /intent`)**:
  - Must send `session_id` and `offer_id`:
    ```json
    {
      "session_id": "s_ca99bb83",
      "type": "buy",
      "source": "button",
      "offer_id": "monday-cartoons.myshopify.com:gid://shopify/ProductVariant/68033173323939:50"
    }
    ```
  - If `offer_id` is missing or stale (including after a change to another item from the same seller), backend returns `handoff.status = "stale_pick"` and `handoff.offer_id = "<current_offer_id>"` and clears any active QR.
